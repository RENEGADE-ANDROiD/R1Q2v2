02 / MAKE IT YOURS

Old-school game.
More room to tune it.

Classic menus and movement, with thoughtful additions for modern screens. These captures use the original Quake II textures and weapons.

01

Your HUD.
Your screen.

Move the stock status bar to the top, spread it across a widescreen display, or keep the classic layout. Adjust its scale without resizing the menus.

02

A clearer view.
A familiar world.

Build 8065 eases the harsh sodium-yellow cast of baked lighting. Switch between the softened look and classic lighting in real time, without reloading the map.

gl_less_yellow
Original textures stay intact. Colored accent lights keep their character.

A place to play

Browse public servers and LAN games. Keep favorites in an Address Book that survives config reloads and game-directory switches.

Download release ZIP ↓
Release notes ↗SHA-256 ↗
Requires an existing Quake II installation. Retail / Steam game data is not included.
  1. 01

    Start with Quake II

    Install the original game. Quit any running Quake II client and back up your existing binaries.

  2. 02

    Extract the release

    Place the files next to quake2.exe. For local single-player, also place gamex86.dll in baseq2/.

  3. 03

    Launch and tune

    Run R1Q2v2.exe. Explore the menus or open the CVAR guide to set it up your way.
